## Usage

```tsx
import { IconField } from '@primereact/ui/iconfield';
```

```tsx
<IconField>
    <IconField.InputIcon />
    <InputText />
</IconField>
```

## Accessibility

### Screen Reader

IconField and InputIcon do not require any roles and attributes.

### Keyboard Support

Components does not include any interactive elements.
