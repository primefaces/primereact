## Usage

```tsx
import { FloatLabel } from '@primereact/ui/floatlabel';
```

```tsx
<FloatLabel>
    {/* input element like InputText, InputNumber, Select, Textarea, input etc. */}
    {/* label element like Label, label etc. */}
</FloatLabel>
```

## Examples

### Variants

The `variant` property defines the position of the label. Default value is `over`, whereas `in` and `on` are the alternatives.

<DocDemoViewer name="floatlabel:variants-demo" />

### Invalid

When the form element is invalid, the label is also highlighted.

## Accessibility

### Screen Reader

FloatLabel does not require any roles and attributes.

### Keyboard Support

Component does not include any interactive elements.
